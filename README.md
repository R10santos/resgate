# Resgate

## Jogar a versão pronta no Windows (64 bits)

1. [Baixe Eco7-Windows.zip](https://github.com/R10santos/resgate/raw/refs/heads/main/Eco7-Windows.zip).
2. Clique com o botão direito no ZIP e escolha **Extrair Tudo...**.
3. Abra a pasta extraída **Eco7** e dê dois cliques em **iniciar.cmd**.

O pacote inclui o executável e as licenças. Não é necessário instalar Python
nem baixar dependências para jogar. Extraia o ZIP antes de iniciar o jogo.

## Código do projeto

O jogo **ECO-7 — Protocolo Aurora** está na pasta [resgate/](resgate/README.md),
junto com o código, os inicializadores, os testes, a documentação e as licenças.

No Windows, abra `resgate\iniciar.cmd`. Para executar pelo código ou gerar o
executável, siga o [README do projeto](resgate/README.md).

Para trabalhar no código pelo editor, abra a subpasta `resgate` como projeto.
